# Pets & Cia Petshop

Projeto acadêmico da **Fase 2** da disciplina **Fundamentos de Sistemas Web**, do curso de Análise e Desenvolvimento de Sistemas da PUCRS.

A Fase 2 dá continuidade ao site desenvolvido na etapa anterior e acrescenta recursos visuais, interatividade, cadastro e agendamento.

## Funcionalidades

- layout responsivo com CSS e Bootstrap;
- carrossel de destaques na página inicial;
- catálogo de acessórios, rações não perecíveis e produtos de higiene;
- serviços de banho e tosa;
- formulário de cadastro do cliente com nome, endereço, CPF, sexo, telefone e e-mail;
- formulário de cadastro do pet com nome, raça e idade;
- seleção de serviço e do método de atendimento por tele-busca ou entrega do pet no local;
- escolha de data e horário para o agendamento;
- JavaScript para relógio, máscaras de CPF e telefone, comportamento do formulário e resumo do agendamento;
- recursos de acessibilidade, incluindo textos alternativos nas imagens, link para conteúdo principal, foco de teclado e modo de alto contraste;
- página de ajuda com a descrição das funcionalidades.

## Ajustes realizados na Fase 2

A estrutura da Fase 1 foi preservada e reorganizada para utilizar Bootstrap e um arquivo CSS próprio. A navegação foi transformada em menu responsivo, os produtos e serviços foram organizados em cartões e foi criado um carrossel na página inicial. Também foi incluída uma página específica para cadastro e agendamento. O JavaScript foi separado em arquivo próprio para manter o código organizado e executar as funções dinâmicas. Foram adicionadas validações básicas do formulário e melhorias de acessibilidade.

## Estrutura de arquivos

- `index.html` - página inicial e carrossel;
- `produtos.html` - catálogo de produtos;
- `servicos.html` - apresentação dos serviços;
- `cadastro.html` - cadastro de cliente, pet e agendamento;
- `ajuda.html` - arquivo de ajuda do sistema;
- `css/style.css` - estilos próprios;
- `js/script.js` - funções JavaScript.
